> 
> *   **Frontend:** HTML, Bootstrap 4, Font Awesome 5
> *   **Features:** ParsleyJS, DataTables, MomentJS, Tempus Dominus (datetime picker), PrismJS

Feel free to use this template for your admin-dashboard projects.
